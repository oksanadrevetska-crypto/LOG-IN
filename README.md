# LOG-IN

Репозиторій HTML-сторінок курсу онбордингу "LOG-IN" для стажерів SIBWAY LOGISTICS. Сторінки вставляються в конструктор Systeme.io через блок "Необроблений HTML".

## Структура

- **`rules/pravyla-storinok-kursu.md`** — правила оформлення HTML-сторінок: кольори, шрифт, навігація, робота з зображеннями, технічні обмеження платформи Systeme.io. Читати перед створенням чи редагуванням будь-якої сторінки.
- **`rules/project-context.md`** — контекст курсу, покажчик усіх 47 тем із посиланнями на джерела на Google Drive, статус перевірки документів, зафіксовані рішення.
- **`pages/module-1/`** — готові сторінки Модуля 1 (Знайомство з компанією, правилами та роллю).
- **`pages/module-2/`** — готові сторінки Модуля 2 (Інфраструктура ринку та географія).

## Як користуватись файлом сторінки

Кожен `.html`-файл — це фрагмент коду (не повний документ), призначений для вставки в блок "Необроблений HTML" у редакторі Systeme.io. Копіювати весь вміст файлу цілком і вставляти замість попереднього коду блоку.
